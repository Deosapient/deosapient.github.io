Політика конфіденційності

Чинна редакція від 8 жовтня 2026 року

Miya Assistant — особистий асистент, який адмініструє Deosapient. Застосунок призначений для власника та користувачів, яких він особисто допустив до свого асистента. Ця політика пояснює обробку даних Google і відвідування цього сайту.

1. Які дані використовуються і навіщо

Доступ залежить від дозволів, підтверджених конкретним користувачем у Google OAuth. Застосунок використовує дані для виконання його доручень.

Технічний обсяг OAuth може бути ширшим за конкретне доручення. Наданий доступ сам по собі не є командою надсилати листи, публікувати файли або видаляти дані. Такі дії підпорядковуються дорученням власника.

2. Де обробляються дані та кому вони передаються

  • Google надає API й зберігає оригінали матеріалів у підключених сервісах.
  • Приватний сервер асистента виконує доручення, зберігає стан роботи, історію розмов та потрібну пам’ять. Власник адмініструє цей сервер.
  • Обрані AI-провайдери, зокрема Anthropic та OpenAI, можуть отримувати потрібні для доручення фрагменти даних, якщо завдання передбачає їх аналіз або створення відповіді. Обробка відбувається за умовами відповідного сервісу й налаштуваннями облікового запису. Ця політика не обіцяє нульового зберігання у провайдера.
  • Telegram обробляє повідомлення, надіслані асистентові або ним у чаті. Відповіді можуть містити результати роботи з даними Google.
  • Одержувачі, визначені користувачем, отримують листи, запрошення або матеріали лише в межах дорученої дії.

Розробник не продає дані Google, не використовує їх для реклами або навчання узагальнених AI-моделей. Передача даних обмежується виконанням доручень, необхідною роботою сервісів і вимогами закону. Використання інформації, отриманої через Google API, відповідає Google API Services User Data Policy, включно з вимогами Limited Use.

3. Зберігання й захист

Токени OAuth зберігаються на приватному сервері й використовуються для дозволених API-запитів. Вони не публікуються на цьому сайті. Підключення до Google API відбувається через HTTPS; доступ до серверних даних обмежується його обліковими записами й правами.

Вміст доручень, відповіді та результати можуть залишатися в історії, пам’яті, робочих файлах і резервних копіях асистента. Єдиного автоматичного строку видалення для всіх цих даних не встановлено: вони зберігаються для продовження роботи, доки власник не визначить їх непотрібними або не надасть доручення видалити. Копії в резервуванні можуть зберігатися до завершення відповідного циклу ротації. Абсолютна безпека даних не гарантується.

4. Відкликання доступу й видалення

Користувач може відкликати доступ Miya Assistant у розділі підключень Google-акаунта. Це припиняє подальший доступ через відкликану авторизацію, але саме по собі не стирає раніше збережену історію або робочі копії.

Для видалення локальних даних і токенів власник може дати окреме доручення у своєму приватному каналі керування Мією. Допущений користувач може звернутися до адміністратора через узгоджений приватний канал. Питання про контактний спосіб можна адресувати розробникові на GitHub; не публікуйте там листи, токени чи інші особисті дані.

5. Цей публічний сайт

Сайт розміщено на GitHub Pages. Його сторінки не містять форм авторизації, рекламних трекерів або власної аналітики. GitHub може обробляти технічні дані відвідування відповідно до своєї політики конфіденційності. Приватні дані Google не розміщуються в публічному репозиторії сайту.

6. Зміни та контакт

Актуальна редакція політики доступна на цій сторінці. Зміни відображаються датою редакції. Перед розширенням використання даних за межі описаного призначення потрібне відповідне інформування та погодження користувача.
